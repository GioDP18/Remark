
# Team Workflow Challenge

## About the Project

This project is a simple website created by our
team to practice Git and GitHub collaboration.

## Project Features

- A homepage introducing our project
- A section about team collaboration
- Basic styling using CSS

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Team Responsibilities

- Member 1: Lead Developer
- Member 2: Feature Developer
- Member 3: Documentation Developer

## What We Learned

Through this activity, we practiced creating
branches, committing changes, pushing to GitHub,
opening pull requests, and reviewing contributions.
